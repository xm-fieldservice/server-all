#### 1.2 新增语义分类API
**端点：** `POST /api/memory/classify`

**功能：**
- 基于规则分析输入内容
- 返回 `msg_type`（question/statement）
- 返回 `is_question` 布尔值
- 支持置信度评估

**规则逻辑：**
```python
question_keywords = ["什么", "如何", "怎么", "为什么", "哪个", "怎样", "?", "？"]
note_keywords = ["记录", "笔记", "备忘", "待办", "todo", "会议", "总结"]

if any(kw in content_lower for kw in question_keywords):
    msg_type = "question"
elif any(kw in content_lower for kw in note_keywords):
    msg_type = "statement"
```

---

#### 1.3 新增完整问答API
**端点：** `POST /api/memory/chat`

**功能：**
- 整合笔记入库和问答检索
- 支持三种模式：note/qa/auto
- 支持语义分析自动判断
- 生成Agent回答（简化版）
- 保存用户消息和助手消息

**请求格式：**
```json
{
    "session_id": "session_xxx",
    "user_id": "user_001",
    "assistant_id": "assistant_001",
    "content": "用户输入的内容",
    "mode": "auto",  // note/qa/auto
    "search_mode": "rag"  // rag/web/hybrid
}
```

**响应格式：**
```json
{
    "user_message_id": "msg_xxx",
    "assistant_message_id": "msg_yyy",
    "is_question": true,
    "answer": "根据记忆库...",
    "mode": "qa"
}
```

    sessionId, userId, assistantId, content, mode, searchMode
