## 1. 什么算“核心工程”（AI 工厂）里的东西？

建议都归入 **AI 工厂核心工程** 的，是这些“能力与编排层”的东西：

- **Agent 相关**  
  - autogen / 自研 agent 框架  
  - MCP 客户端、MCP 工具适配  
  - 各种系统级 prompt、路由策略、任务编排逻辑

- **RAG 能力层**  
  - 向量检索的统一接口（不管底层是 pgvector、Chroma 还是别的）  
  - 文本切分、embedding 调用、重排逻辑  
  - 针对 RAG 的缓存、索引任务调度等

- **各类 LLM/RAG 框架的“封装层”**  
  - langchain 的 chain / retriever 封装  
  - llamaindex 的 index / query engine 封装  
  - 将来引入的 neo4j / graphrag 的“统一访问接口”

- **数据访问与配置封装**  
  - 连接 PostgreSQL（含 pgvector）的 client 封装  
  - 后面如果有 Neo4j，也放统一的 graph client 封装  
  - 统一读取环境变量 / 配置文件（连接串、API key 等）

**总结一句：**  
所有“**跟 AI 能力、数据访问、编排逻辑相关的通用代码**”，都放在 AI 工厂核心工程里。

## 2. 什么不必算在“核心工程”里？

- **数据库本身的安装/运行实例**：
  - 本机 PostgreSQL、Docker pgvector 容器、将来的 Neo4j 进程  
  - 它们是**基础设施**，不属于代码工程的一部分；
  - 在核心工程里，只有“怎么连它们”的代码与配置。

- **具体业务应用/UI**：
  - [injection-legacy-columns](cci:7://file:///d:/AI/injection-legacy-columns:0:0-0:0) 的三栏界面和特定脚本  
  - [desktop_app](cci:7://file:///d:/AI/desktop_app:0:0-0:0) 的 PC UI  
  - 某个具体业务的 REST API 控制器  
  这些属于“应用层工程”，只通过接口使用核心工程。

## 5. AI 工厂包内部模块清单（收口自《AI工厂架构清单和职责草案》）

> 本节整合自《AI工厂架构清单和职责草案》，该草案文档后续不再单独作为权威规范，遇到不一致时以本节与四份核心文档为准。

- `ai_factory.config`
  - 职责：统一读取 .env / 环境变量、日志配置等。

- `ai_factory.db`
  - 职责：数据库访问与仓储层，例如：
    - `pgvector_client`：Postgres/pgvector 连接封装；
    - `entries_repo`：`entries` 事实表的插入与基础查询；
    - `nodes_repo`：基于 `entries.scene_tags` 的 Node Query SQL 等。

- `ai_factory.agents`
  - 职责：Agent / Team 的配置、挂载和运行时工厂，负责把模型、工具、Memory 组装为可执行的 Agent 组合。

- `ai_factory.rag`
  - 职责：向量检索与 RAG 流水线封装，对上提供统一的检索接口。

- `ai_factory.tools`
  - 职责：管理 Function Tool / MCP 等工具类组件的注册表与加载逻辑。

- `ai_factory.frameworks`
  - 职责：对 AutoGen / LangChain / LlamaIndex / GraphRAG 等外部框架做适配封装，使上层只依赖 ai_factory 自己的接口。

- `ai_factory.testing` / `ai_factory.lab`
  - 职责：性能评测、基准测试与结果落库，为“货架视图”和方案对比提供数据基础。

- `ai_factory.shelf`
  - 职责：对外提供“货架视图”的统一查询接口，聚合各类组件与评测结果，支持按标签/指标过滤与排序。

- `ai_factory.integrations`
  - 职责：对上层应用（问答系统、三栏/五栏 UI 等）暴露高层 API，如 `entries_ingest`、`qa_answer_rag`、`qa_answer_web`、场景标签 Node Query 等。

- `ai_factory.cli`
  - 职责：命令行入口，支撑在 CI/终端环境下执行“生成 Agent 配置 / 跑评测 / 导出货架视图”等操作。
