[entries_ingest.py](cci:7://file:///d:/AI/ai-factory/ai_factory/integrations/entries_ingest.py:0:0-0:0) 里：

- 定义了 [EntryIngestionResult](cci:2://file:///d:/AI/ai-factory/ai_factory/integrations/entries_ingest.py:17:0-21:30)（dataclass）
  - 字段：`entries: List[ChunkResult]`
  - [ChunkResult](cci:2://file:///d:/AI/ai-factory/ai_factory/agents/entry_agents.py:17:0-23:16) 已在 `ai_factory.agents.entry_agents` 中定义（`entry_id/title/content`）。

- 核心函数：

```python
def entries_ingest(payload: Dict[str, Any]) -> Dict[str, Any]:
    """
    高层入口：处理原始输入并写入 entries。
    期望 payload:
      - raw_text: str
      - project_code / user_id / note_datetime: 可选
      - extra_context: dict 可选
    返回:
      { "entries": [ {entry_id, title, content}, ... ] }
    """
```

- 内部流程：
  1. 取出并检查 `payload["raw_text"]`，为空就抛 `ValueError`（防止误调用）。
  2. 把 `project_code / user_id / note_datetime` 和 `extra_context` 合并成 `base_meta`。
  3. 调用现有的 [entries_chunk_agent(raw_text, base_meta)](cci:1://file:///d:/AI/ai-factory/ai_factory/agents/entry_agents.py:26:0-58:17)：  
     - 内部完成“按空行切块 + 生成 entry_id/title + 调 [entries_repo.insert_entry](cci:1://file:///d:/AI/ai-factory/ai_factory/db/entries_repo.py:15:0-32:37) 写入 entries”。
  4. 把 [ChunkResult](cci:2://file:///d:/AI/ai-factory/ai_factory/agents/entry_agents.py:17:0-23:16) 列表转成 JSON 友好的 dict，返回：

     ```jsonc
     {
       "entries": [
         {"entry_id": "...", "title": "...", "content": "..."},
         ...
       ]
     }
     ```

> 这就已经是一个可以很容易挂 HTTP 的后端函数了（无状态、纯入参/出参）。

## 二、现在三栏 PM 理论上可以怎么对接（最小方案）

在你不改 HTTP 服务的前提下，他可以有两个选择：

1. **本机 Python 直接调用（开发/内网阶段）**
   - 在 Qt 项目里通过 Python 嵌入或通过现有 Python 后端进程，调用：
     ```python
     from ai_factory.integrations.entries_ingest import entries_ingest

     result = entries_ingest({
         "raw_text": "...",
         "project_code": "...",
         "user_id": "...",
         "note_datetime": "...",
         "extra_context": {"source": "three_column_ui"},
     })
     # result["entries"][0]["entry_id"] / ["title"] / ["content"]
     ```

2. **将来挂成 HTTP API**
   - 你或我这边再加一个很薄的 FastAPI/Flask 层：
     - `POST /api/entries/ingest` → 内部 [entries_ingest(request.json)](cci:1://file:///d:/AI/ai-factory/ai_factory/integrations/entries_ingest.py:24:0-56:5) → 返回 JSON。
   - 三栏那边无感，只知道调用 HTTP 即可。
