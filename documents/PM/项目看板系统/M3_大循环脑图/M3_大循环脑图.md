## 一、模块概述

### 1.1 核心定位

```
脑图 = 父子关系数据的展示器 + 编辑器（一体两面）+ 推理可视化工具
展示即编辑，编辑即展示
```

### 1.2 系统角色

| 角色 | 说明 |
|------|------|
| 核心视图 | 用户进入系统的主要视图 |
| 集成枢纽 | 连接多个模块的数据和能力 |
| 大循环可视化 | 战略→目标→规划→计划→项目→工作流的可视化展示 |
| 小循环容器 | 笔记、议题、任务、日程的附属管理 |
| **推理可视化工具** | 逻辑推理、阶段演进的可视化展示 |
| **场景驱动展示** | 不同场景下展示不同的关系类型和视觉表达 |

## 三、节点属性

### 3.1 结构性属性（固定字段）

| 字段名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| id | UUID | 是 | 节点唯一标识 |
| title | VARCHAR(500) | 是 | 节点标题 |
| content | TEXT | 否 | 节点内容（富文本） |
| attachments | JSONB | 否 | 附件列表 |
| node_type | ENUM | 是 | 节点类型 |
| parent_id | UUID | 否 | 父节点ID |
| status | ENUM | 否 | 状态标签 |
| created_at | TIMESTAMP | 是 | 创建时间 |
| updated_at | TIMESTAMP | 是 | 更新时间 |
| created_by | UUID | 是 | 创建者 |
| visibility | ENUM | 否 | 可见性（权限控制） |

### 3.2 动态内容类（JSONB字段）

```json
{
  "dynamic_tags": ["重要", "紧急", "待跟进"],
  "relations": [
    {"target_id": "uuid-xxx", "type": "dependency", "label": "依赖"},
    {"target_id": "uuid-yyy", "type": "reference", "label": "参考"}
  ],
  "extended_props": {
    "custom_field_1": "value1",
    "custom_field_2": "value2"
  }
}
```

### 3.3 变更履历

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | UUID | 履历记录ID |

| old_value | JSONB | 变更前值 |

## 四、关系规则

### 4.1 关系类型

| 关系类型 | 说明 | 示例 |
|----------|------|------|
| 父子关系 | 核心关系，形成树形结构 | 战略→计划、项目→任务 |
| 关联关系 | 非层级的引用关系 | 计划A关联项目B |
| 依赖关系 | 前置条件关系 | 任务A依赖任务B |
| 参考关系 | 信息引用关系 | 笔记参考某个战略 |
| 自定义关系 | 用户动态定义 | 任意自定义关系类型 |

### 4.2 大小循环交互规则

```
规则1: 小循环节点必须附属大循环节点
├── 笔记、议题、任务、日程 不能作为根节点
└── 必须附属某个大循环节点

规则2: 散装内容归属"其他"节点
├── 无明确归属的笔记/议题
└── 自动放入"其他"系统节点下

规则3: 一个小循环节点可关联多个大循环节点
├── 一个笔记可以关联多个战略/计划
└── 通过"关联关系"实现，非父子关系
```

### 4.3 拖拽规则

| 操作 | 效果 | 履历记录 |
|------|------|----------|
| 拖拽改变父子关系 | 更新parent_id | 记录old_parent→new_parent |
| 拖拽改变归属关系 | 更新附属关系 | 记录old_owner→new_owner |
| 跨类型拖拽 | 检查是否允许 | 记录类型变化 |

### 4.4 场景驱动的关系表达

**核心概念**：关系类型 + 视觉表达 = 场景定义

不同场景下，脑图展示不同的关系类型和视觉表达：

| 场景 | 关系类型 | 线型 | 节点属性 | 允许的节点类型 |
|------|----------|------|----------|----------------|
| 大循环场景 | 父子关系（合集-子集） | 实线、默认粗细 | 按节点类型区分 | 战略/目标/规划/计划/项目/任务 |
| 关系管理场景 | 逻辑关系、父子关系 | 可配置（实线/虚线/箭头） | 按关系类型区分 | 任意节点 |
| 工作流场景 | 阶段关系（顺次） | 带箭头、流程线 | 按阶段区分 | 工作流节点+任务节点 |
| 自定义场景 | 用户定义 | 用户定义 | 用户定义 | 用户定义 |

**场景配置能力**：

```
每个场景可配置：
├── 关系类型定义
│   ├── 允许的关系类型
│   └── 关系类型语义
├── 视觉表达
│   ├── 连线样式（实线/虚线/点线）
│   ├── 连线颜色
│   ├── 箭头样式
│   └── 连线标签
├── 节点外观
│   ├── 节点形状
│   ├── 边框颜色/样式
│   ├── 背景色
│   └── 图标
└── 交互规则
    ├── 允许的操作
    └── 操作约束
```

**推理可视化**：

脑图作为推理可视化工具，支持：

| 推理类型 | 表达方式 | 示例 |
|----------|----------|------|
| 纵向推理 | 节点间推导关系 | 前提→推导→结论 |
| 阶段演进 | 纵向阶段标示 | 阶段1→阶段2→阶段3 |
| 横向推理 | 父子关系扩展 | 节点A推理出节点B |

## 五、数据来源

### 5.1 来源分类

| 来源 | 处理方式 | 可信度 | 自动化程度 |
|------|----------|--------|------------|
| 人工输入 | 直接创建 | 高 | 手动 |
| AI问答记录 | 部分自动创建 | 中 | 半自动 |
| 企业微信聊天 | AI识别+人工确认 | 低 | 半自动 |
| AI轮巡报告 | AI生成+人工确认 | 中 | 半自动 |
| 笔记感想 | 直接创建 | 高 | 手动 |
| 外部系统同步 | 按规则自动创建 | 中 | 自动 |

### 5.2 数据写入流程

```
┌─────────────────────────────────────────────────────────────┐
│                    数据写入流程                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  高可信来源（人工输入、笔记感想）                            │
│  ────────────────────────────────→ 直接创建节点             │
│                                                             │
│  中可信来源（AI问答、AI报告）                                │
│  ────────────────────────────────→ 建议 → 人工确认 → 创建   │
```

## 六、Agent能力

### 6.1 按节点类型的Agent配置

| 节点类型 | 默认Agent | Agent能力 |
|----------|-----------|-----------|
| 战略 | 战略分析Agent | 环境分析、竞争分析、趋势预测 |
| 目标 | 目标追踪Agent | 进度追踪、风险预警、达成分析 |
| 规划 | 规划辅助Agent | 资源评估、路径规划、方案对比 |
| 计划 | 动态调整Agent | 项目变化分析、计划自动调整、轮巡反馈 |
| 项目 | 项目轮巡Agent | 进度监控、风险预警、状态汇总 |
| 工作流 | 流程执行Agent | 信息采集、流程执行、状态更新 |

### 6.2 Agent配置方式

```
┌─────────────────────────────────────────────────────────────┐
│                    Agent配置方式                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  方式1: 右键菜单配置                                        │
│  ├── 右键节点 → 选择Agent → 配置参数                        │
│  └── 支持多个Agent协作                                      │
│                                                             │
│  方式2: 节点类型预设                                        │
│  ├── 每种节点类型有默认Agent模板                            │
│  └── 用户可在此基础上增删改                                 │
│                                                             │
│  方式3: Agent货架选择                                       │
│  ├── 从M5 Agent货架选择已注册的Agent                        │
│  └── 支持自定义Agent注册                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 6.3 Agent触发方式

| 触发方式 | 说明 | 示例 |
|----------|------|------|
| 手动触发 | 用户主动调用 | 右键菜单"分析" |
| 定时触发 | 按计划自动执行 | 每日轮巡 |
| 事件触发 | 状态变化时触发 | 项目进度变化时预警 |
| 条件触发 | 满足条件时触发 | 进度<50%时提醒 |

### 8.2 场景切换机制

**核心交互**：工具栏场景开关控制当前添加节点的样式

| 交互 | 效果 |
|------|------|
| 点击场景开关 | 激活/取消激活该场景 |
| 多场景叠加 | 可同时激活多个场景 |
| 添加节点 | 新节点采用当前激活场景的样式 |
| 切换场景 | 后续节点采用新激活场景的样式 |

**场景叠加示例**：

```
操作序列：
1. 激活[大循环] → 添加战略→计划→项目（大循环节点样式）
2. 激活[工作流] → 在项目后添加节点1→节点2→节点3（顺次样式）
3. 激活[逻辑关系] → 在节点后添加推理节点（推理线型）

结果：一个脑图包含多种场景的节点，形成复合视图
```

**数据同步**：

| 场景操作 | 数据层同步 |
|----------|------------|
| 添加节点 | 写入entries，记录场景类型 |
| 创建关系 | 写入关系表，记录关系类型 |
| 切换场景 | 更新当前场景状态 |
