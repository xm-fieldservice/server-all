## 附录二：设计原则说明

### 1. 微流程功能模块的定位

> **重要说明**：微流程是架构设计的抽象概念，实际实现时是**功能模块/组件**，而非"微流程引擎"。

**设计原则**：
- 货架模式：勾选即启用，不选即禁用
- 功能模块：配置开关+参数，非流程编排
- 可扩展性：新增功能只需增加模块

**与告警机制的区别**：

| 维度 | 功能模块(11.5) | 告警机制(11.3) |
|------|----------------|-----------------|
| 定位 | 节点的可选能力 | 系统级监控 |
| 触发 | 用户主动触发 | 系统自动触发 |
| 粒度 | 节点级别 | 实例/任务级别 |
| 灵活性 | 可配置 | 规则驱动 |

### 2. 升级机制的双重属性

升级机制包含两种模式：

| 模式 | 说明 | 位置 |
|------|------|------|
| **主动升级** | 节点处理人主动发起升级 | 11.5.3(1) 功能模块 |
| **被动升级** | 规则触发或AI判断触发升级 | 11.6 事故升级机制 |

**设计意图**：
- 主动升级 = 用户权利（功能模块）
- 被动升级 = 系统能力（规则/AI）

### 3. 绩效评估的定位

绩效评估是**架构级**的核心模块：

- 无论自动/人工，所有工作流都需要绩效评估
- 评估结果可对接BSC/KPI/个人档案系统
- 评估数据自动采集、计算、记录

## 附录四：数据表整合建议

### 建议整合后的核心表

```sql
-- 工作流定义表 (合并版本管理、权限配置)
CREATE TABLE workflow_definitions (
    workflow_id VARCHAR(50) PRIMARY KEY,
    workflow_name VARCHAR(200) NOT NULL,
    category VARCHAR(50),
    version VARCHAR(20) NOT NULL,
    definition JSONB NOT NULL,
    
    -- 权限配置
    owner_department VARCHAR(50),
    owner_user VARCHAR(50),
    permission_config JSONB,
    
    -- 状态
    status VARCHAR(20) DEFAULT 'draft',
    
    -- 版本管理
    parent_version VARCHAR(20),
    change_log TEXT,
    
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 工作流实例表 (合并上下文、权限)
CREATE TABLE workflow_instances (
    instance_id VARCHAR(50) PRIMARY KEY,
    workflow_id VARCHAR(50) REFERENCES workflow_definitions(workflow_id),
    version VARCHAR(20),
    
    -- 流程状态
    current_node VARCHAR(50),
    status VARCHAR(20) DEFAULT 'running',
    
    -- 上下文
    initiator VARCHAR(50) NOT NULL,
    variables JSONB,
    context JSONB,
    
    -- 权限
    permission_config JSONB,
    
    -- 时间
    started_at TIMESTAMP DEFAULT NOW(),
    completed_at TIMESTAMP,
    duration_seconds INT,
    
    -- 版本
    instance_version INT DEFAULT 1
);

-- 任务表 (统一任务、记录、评价)
CREATE TABLE workflow_tasks (
    task_id VARCHAR(50) PRIMARY KEY,
    instance_id VARCHAR(50) REFERENCES workflow_instances(instance_id),
    node_id VARCHAR(50) NOT NULL,
    
    -- 责任人
    assignee VARCHAR(50),
    handler VARCHAR(50),
    
    -- 状态
    status VARCHAR(20) DEFAULT 'pending',
    priority VARCHAR(20) DEFAULT 'normal',
    
    -- 时间
    created_at TIMESTAMP DEFAULT NOW(),
    started_at TIMESTAMP,
    due_at TIMESTAMP,
    completed_at TIMESTAMP,
    
    -- 内容
    title VARCHAR(200),
    content TEXT,
    form_data JSONB,
    comments TEXT,
    attachments JSONB,
    
    -- 记录功能
    documentation JSONB,
    
    -- 升级记录
    escalation_history JSONB,
    
    -- 评价
    rating JSONB
);
```
