## 一、系统定位

│  │  AI工厂     │  │  知识工厂   │  │ 能力运营中心 │        │
│  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘        │
│         │                │                │                │
│         └────────────────┼────────────────┘                │
│                          │                                 │
│                          ▼                                 │
│              ┌───────────────────────┐                    │
│              │  项目看板系统（本系统）│                    │
│              │  - 8个模块具体落地     │                    │

### 1.2 核心定位

| 维度 | 说明 |
|------|------|
| **系统边界** | 大一统系统（战略→目标→规划→计划→项目→任务→笔记→日程→议题） |
| **向上承接** | 双向关联（项目可关联战略/目标/计划，双向追溯） |

## 三、双循环管理框架

### 3.1 大循环与小循环

项目看板系统是**双循环管理体系的唯一结合点**：

```
【大循环】战略 → 目标 → 规划 → 计划 ──→ 项目 ←─ 小循环【】
                    │                    │                   │
                    └────┴────────────────┼──→ 工作流          │
                                        │                    │
                             【项目 = 唯一结合点】              │
                                        │                    │
                             ┌──────────▼──────────┐         │
                             │    项目看板系统      │         │
                             │  (本系统)           │         │
                             └─────────────────────┘         │
```

### 3.2 循环特征

| 循环 | 特征 | 节点类型 |
|------|------|----------|
| **大循环** | 宏观管理流程，战略到项目的转化 | 战略/目标/规划/计划/项目/工作流 |
| **小循环** | 微观管理支撑，弥散到所有模块 | 任务/笔记/日程/议题 |

## 五、需求采集方法论

### 5.1 三维需求体系

| 维度 | 视角 | 描述方式 | 图谱表达 |
|------|------|----------|----------|
| **第1维** | 用户视角 | 面板→功能（线性） | Panel -[:DISPLAYS]-> Feature |
| **第2维** | 模块视角 | 模块→辐射（去中心化） | Module -[:CONTAINS]-> Feature |
| **第3维** | 关系视角 | 动态关联（深度边界） | Feature -[:DEPENDS_ON]-> Feature |
| **第4层** | 决策层 | 自举式开发决策 | 动态优先级评估 |

### 5.2 采集流程

采集每个模块时，按以下步骤：

| 步骤 | 操作 | 说明 |
|------|------|------|
| **1** | 确认三体位置 | 模块属于AI工厂/知识工厂/能力运营中心的哪个 |
| **2** | 引用总纲概念 | 引用能力工厂总纲中对应章节的核心概念 |
| **3** | 补充特有需求 | 补充本项目特有的需求细节 |
| **4** | 标注差异扩展 | 标注与总纲的差异或扩展 |

### 5.3 采集效率提升

**在总纲指导下**：

```
总纲方法论（能力工厂三体）
        │
        ├──→ 明确模块边界（属于哪个三体）
        ├──→ 复用核心概念（存储/Agent/编排等）
        ├──→ 避免重复定义（统一术语）
        └──→ 发现遗漏（三体完整性检查）
```
