## 二、问题记录

### 问题1: CDN不可用
- **现象**: 环境无法访问 cdn.jsdelivr.net
- **解决**: 改用 npm 安装 jsmind 包
- **命令**: `npm install jsmind`

### 问题2: jsMind拖拽插件引入路径错误
- **现象**: 引入 `jsmind/es6/jsmind.draggable-node.js` 报错
- **解决**: 改为 `jsmind/draggable-node`
- **代码**:
```javascript
import jsMindDraggable from 'jsmind/draggable-node'
```

### 问题3: 拖拽线条颜色看不清
- **现象**: 默认线条颜色为黑色，与背景对比度低
- **解决**: 在拖拽配置中指定 `line_color: '#4ec9b0'`
- **代码**:
```javascript
new jsMindDraggable(jm.value, {
  line_color: '#4ec9b0',
  line_width: 3,
  line_color_invalid: '#f48771'
})
```

### 问题4: 双击节点无法编辑
- **现象**: 双击节点后无反应或报错
- **原因**: jsMind 使用 `topic` 字段存储节点文本，而非 `text`
- **解决**: 在 `transformToJsMind` 函数中使用 `topic` 替代 `text`
- **代码**:
```javascript
function transformToJsMind(node) {
  const result = {
    id: node.id,
    topic: node.title,  // 之前错误使用 text: node.title
    expanded: true
  }
  // ...
}
```
