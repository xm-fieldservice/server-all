## 一、大视角定位

### 1.1 在双循环中的位置

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          双循环管理体系                                  │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  【大循环】                                                              │
│  战略 → 目标 → 规划 → 计划 ──────────────┐                              │
│                                          │                              │
│                              【唯一结合点】│                              │
│                                          ▼                              │
│                    ┌─────────────────────────────────┐                  │
│                    │        项目看板系统              │                  │
│                    │      (本次设计目标)              │                  │
│                    └─────────────────────────────────┘                  │
│                                          ▲                              │
│                              【弥散支撑】│                              │
│                                          │                              │
│  【小循环】                              │                              │
│  任务 ←─ 笔记 ←─ 日程 ←─ 议题 ───────────┘                              │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 1.2 核心定位

| 维度 | 定位 |
|------|------|
| **系统边界** | 大一统系统（战略→目标→规划→计划→项目→任务→笔记→日程→议题） |
| **向上承接** | 双向关联（项目可关联战略/目标/计划，双向追溯） |
| **向下支撑** | 内置子系统（任务/笔记/日程/议题内置） |
| **工作流关系** | 双轨并行（独立系统，互不隶属） |
| **核心价值** | 可视化追踪 > 协作执行 > 知识沉淀 |

### 1.3 与 PM-Framework 的关系

项目看板系统是 **PM-Framework 四大支柱**的工具化落地：

| 支柱 | 工具化体现 |
|------|------------|
| 完整的项目管理规则 | 系统内置标准流程、状态流转、权限控制 |
| 专业分工的Agent团队 | 预留 Agent 接口，支持自动化操作 |
| 完整的工作流运行机制 | 与工作流系统并行，互为补充 |
| 项目知识库构建与运行 | 笔记系统、标签体系、知识沉淀 |

### 3.2 核心实体定义

#### 3.2.1 项目 (Project)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | ✓ | 主键 |
| name | VARCHAR(255) | ✓ | 项目名称 |
| description | TEXT | | 项目描述 |
| owner_id | UUID | ✓ | 项目负责人 |
| status | ENUM | ✓ | 状态: active/archived/completed |
| progress | INTEGER | | 进度百分比 (0-100) |
| start_date | DATE | | 开始日期 |
| end_date | DATE | | 结束日期 |
| **strategy_id** | UUID | | 关联战略（预留） |
| **goal_id** | UUID | | 关联目标（预留） |
| **plan_id** | UUID | | 关联计划（预留） |
| created_at | TIMESTAMP | ✓ | 创建时间 |
| updated_at | TIMESTAMP | ✓ | 更新时间 |

#### 3.2.2 任务 (Task) - 自由层级

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | ✓ | 主键 |
| project_id | UUID | ✓ | 所属项目 |
| parent_id | UUID | | 父任务ID（自关联，支持无限嵌套） |
| label | VARCHAR(500) | ✓ | 任务名称 |
| description | TEXT | | 详细描述 |
| type | ENUM | | 类型: task/milestone/module |
| status | ENUM | ✓ | 状态: pending/active/completed/blocked |
| priority | ENUM | | 优先级: low/medium/high/urgent |
| owner_id | UUID | | 负责人 |
| progress | INTEGER | | 进度百分比 |
| start_date | DATE | | 开始日期 |
| end_date | DATE | | 结束日期 |
| order | INTEGER | | 同级排序 |
| tags | JSONB | | 标签数组 |
| created_at | TIMESTAMP | ✓ | 创建时间 |
| updated_at | TIMESTAMP | ✓ | 更新时间 |

#### 3.2.3 笔记 (Note)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | ✓ | 主键 |
| project_id | UUID | ✓ | 所属项目 |
| task_id | UUID | | 关联任务 |
| title | VARCHAR(255) | ✓ | 标题 |
| content | TEXT | | 内容（支持 Markdown） |
| type | ENUM | | 类型: meeting/tech/summary |
| tags | JSONB | | 标签数组 |
| author_id | UUID | ✓ | 作者 |
| created_at | TIMESTAMP | ✓ | 创建时间 |
| updated_at | TIMESTAMP | ✓ | 更新时间 |

#### 3.2.4 用户与权限

| 实体 | 说明 |
|------|------|
| User | 用户基本信息 |
| ProjectMember | 项目成员关联（user_id, project_id, role） |
| Role | 角色: admin/member/viewer |

## 四、功能需求

### 4.1 核心功能

#### 4.1.1 项目管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 创建项目 | 填写名称、描述、时间范围 | P0 |
| 编辑项目 | 修改项目基本信息 | P0 |
| 归档项目 | 归档已完成项目 | P1 |
| 删除项目 | 管理员可删除项目 | P1 |
| 项目成员 | 添加/移除项目成员 | P0 |
| 项目列表 | 查看所有项目 | P0 |

#### 4.1.2 任务管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 创建任务 | 在项目中创建任务 | P0 |
| 创建子任务 | 在任务下创建子任务（无限层级） | P0 |
| 编辑任务 | 修改任务属性 | P0 |
| 删除任务 | 删除任务（子任务可选择处理） | P0 |
| 任务分配 | 指定任务负责人 | P0 |
| 状态流转 | pending→active→completed/blocked | P0 |
| 进度更新 | 更新任务进度 | P0 |
| 拖拽排序 | 拖拽调整任务顺序和层级 | P1 |

#### 4.1.3 脑图视图（核心视图）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 树形展示 | 以树形结构展示任务层级 | P0 |
| 展开/折叠 | 展开/折叠子任务 | P0 |
| 节点操作 | 右键菜单增删改 | P0 |
| 拖拽调整 | 拖拽调整父子关系 | P1 |
| 缩放平移 | 缩放和平移画布 | P1 |
| 搜索定位 | 搜索任务名称并定位 | P1 |
| 节点样式 | 不同状态不同颜色 | P1 |

#### 4.1.4 列表视图

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 表格展示 | 以表格形式展示任务 | P0 |
| 排序 | 按任意列排序 | P0 |
| 筛选 | 按状态、负责人、日期筛选 | P0 |
| 批量操作 | 批量修改状态、删除 | P1 |
| 导出 | 导出为 CSV/Excel | P2 |

#### 4.1.5 笔记管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 创建笔记 | 创建项目/任务笔记 | P0 |
| Markdown | 支持 Markdown 格式 | P1 |
| 关联任务 | 笔记关联到任务 | P0 |
| 搜索笔记 | 全文搜索笔记内容 | P1 |
| 笔记列表 | 笔记卡片列表展示 | P0 |

### 4.2 用户与权限

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 用户注册 | 邮箱注册 | P0 |
| 用户登录 | 邮箱+密码登录 | P0 |
| 密码重置 | 邮箱验证码重置 | P1 |
| 角色权限 | 管理员/成员/访客 | P0 |
| 项目成员 | 项目级别成员管理 | P0 |
