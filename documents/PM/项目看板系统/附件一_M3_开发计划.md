## 一、开发目标

### 1.1 阶段划分

| 阶段 | 目标 | 交付物 |
|------|------|--------|
| Phase 1 | 基础脑图功能 | 可运行的脑图CRUD |
| Phase 2 | 交互增强 | 右键菜单、场景开关 |
| Phase 3 | 问答集成 | Agent调用、问答→脑图 |
| Phase 4 | 笔记集成 | 笔记面板、笔记→脑图 |
| Phase 5 | 数据层集成 | API对接、真实持久化 |

### 1.2 技术选型

| 技术 | 选型 | 理由 |
|------|------|------|
| 前端框架 | Vue3 + Vite | 现代前端标准 |
| 脑图库 | jsMind (CDN) | 团队熟悉、成熟稳定 |
| 状态管理 | Pinia | Vue3官方推荐 |
| 持久化 | 阶段1: localStorage / JSON文件<br>阶段5: M1数据层API | 渐进式对接 |

## 七、系统架构设计

### 7.1 架构模式：前后端分离

```
┌─────────────────────────────────────────────────────────────┐
│                        前端 (Vue3)                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐       │
│  │   脑图模块   │  │   问答模块   │  │   笔记模块   │       │
│  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘       │
│         │                │                │                 │
│         └────────────────┼────────────────┘                 │
│                          ▼                                  │
│              ┌─────────────────────┐                       │
│              │    状态管理 (Pinia)  │                       │
│              └──────────┬──────────┘                       │
└─────────────────────────┼───────────────────────────────────┘
                          │ API
┌─────────────────────────┼───────────────────────────────────┐
│                         ▼            后端 (Python/FastAPI)   │
│              ┌─────────────────────┐                       │
│              │      API 网关       │                       │
│              └──────────┬──────────┘                       │
│                         │                                   │
│    ┌────────────────────┼────────────────────┐            │
│    ▼                    ▼                    ▼            │
│ ┌──────┐         ┌──────────┐         ┌────────┐         │
│ │M1数据层│         │ M2 AI工厂 │         │ M7关系│         │
│ │Entries│         │ AutoGen   │         │管理   │         │
│ └──────┘         └──────────┘         └────────┘         │
└────────────────────────────────────────────────────────────┘
```

**说明：**
- 前端：Vue3 单页应用，负责UI渲染和用户交互
- 后端：Python FastAPI，提供API服务
- 通信：REST API + WebSocket（实时通信）
- 渐进式：Phase 1-4 使用 localStorage，Phase 5 对接真实后端

### 7.2 模块化设计

| 模块 | 职责 | 边界 |
|------|------|------|
| **脑图模块** | 节点展示、编辑、拖拽 | 独立组件，可复用 |
| **问答模块** | Agent调用、结果展示 | 独立组件，可复用 |
| **笔记模块** | 笔记编辑、关联 | 独立组件，可复用 |
| **状态管理** | 全局状态、持久化 | Pinia Store |

**模块通信：**
- 脑图 ↔ 问答：通过 Pinia 共享状态
- 脑图 ↔ 笔记：通过节点关联关系
- 组件间：props / emit / Pinia

### 7.3 前端技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 框架 | Vue 3.4+ | Composition API |
| 构建 | Vite 5+ | 开发服务器 + 构建 |
| 状态 | Pinia | 官方推荐状态管理 |
| 路由 | Vue Router 4 | 页面路由 |
| 脑图 | jsMind | 思维导图渲染 |
| HTTP | Axios | API 请求 |
| UI | 自定义 | 轻量级，按需引入 |

### 7.5 数据流设计

```
用户操作 → 组件事件 → Composable → Pinia Store → 本地存储
                ↓
           组件响应式更新
```

**Phase 1 数据流：**
1. 用户点击节点 → 调用 `useMindMap` 方法
2. 方法更新 Pinia Store 状态
3. Store 触发 `localStorage` 持久化
4. 组件响应式更新，jsMind 重新渲染
